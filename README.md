## Overview

**JavaScript Master** is a hands-on learning repository that organizes JavaScript fundamentals into focused sections. It contains small, topic-based code examples and practice exercises designed to help learners understand how JavaScript works and build confidence through experimentation.

The repository follows a progressive learning path: it starts with running JavaScript in a browser, introduces the language's core concepts, and then moves through operators, control flow, objects, arrays, and functions.

## Getting Started

### Prerequisites

You can work with the examples using the following tools:

- **A modern web browser** such as Google Chrome, Microsoft Edge, or Firefox.
- **A code editor** such as [Visual Studio Code](https://code.visualstudio.com/).
- **Node.js (recommended)** if you want to execute standalone JavaScript files from the terminal. Download it from [nodejs.org](https://nodejs.org/).

Node.js is optional for browser-based lessons. No framework, database, or third-party package is required by the current repository structure.

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/mhsakibb/JavaScript-Master.git
```

### 2. Open the Project

Move into the project directory:

```bash
cd JavaScript-Master
```

Open the folder in Visual Studio Code:

```bash
code .
```

You can also open the folder manually from your preferred code editor.

---

## Running the Examples

The repository contains two common types of lesson files. Use the method that matches the files in the lesson folder.

### 1. Run a JavaScript File with Node.js

For a standalone JavaScript example, open a terminal in the repository root and execute the file with Node.js.

For example:

```bash
node "Section 02-Basics/01-variables/script.js"
```

Node.js will execute the file and print any `console.log()` output in the terminal.

The quotes around the path are important because some section folder names contain spaces.

### 2. Run an HTML Lesson in a Browser

Some lessons include an `index.html` file that loads or contains JavaScript.

1. Open the relevant lesson folder.
2. Locate its `index.html` file.
3. Open the file in a web browser.
4. Open the browser's Developer Tools and select the **Console** tab to view JavaScript output.

For example, the first browser lesson is located at:

`Section 01 - Getting Started/01-javascript-in-browser/index.html`

### 3. Experiment with the Code

Try changing variable values, function arguments, conditions, and array elements. Run the example again and compare the output. Modifying the examples is an important part of the learning process.

> **Note:** The repository does not currently include a `package.json` or npm scripts, so `npm install` is not required. Run the individual files directly.

## What You Will Practice

By working through the current repository, you will practice:

- **JavaScript fundamentals:** variables, constants, primitive types, dynamic typing, and basic functions.
- **Expressions and operators:** arithmetic, assignment, comparison, equality, logical, ternary, and bitwise operations.
- **Program flow:** conditional statements, loops, branching, and iteration.
- **Problem solving:** FizzBuzz, prime-number checks, grading, counting, and other introductory exercises.
- **Object-oriented concepts:** object creation, factory and constructor functions, references, cloning, and object equality.

## How to Use This Repository

For the most effective learning experience:

1. **Follow the section order.** Start with Section 01 and progress through the fundamentals before moving to later topics.
2. **Read the example code.** Identify the concept demonstrated in each lesson.
3. **Run the code yourself.** Use the browser or Node.js, depending on the lesson files.
4. **Modify the examples.** Change inputs and experiment with different conditions or values.
5. **Practice independently.** Try to solve the exercise again without looking at the existing solution.
6. **Keep your progress organized.** Revisit topics that are difficult and add your own examples as you learn.
